# SDC Hackathon 2026 - Submission Documents

Place the required submission PDFs in this directory before final submission:

1. `SDC2026_TeamName_Preliminary.pdf` - Preliminary submission form
2. `SDC2026_TeamName_TechDeclaration.pdf` - Technology declaration document
3. `SDC2026_TeamName_Replit_POU.pdf` - Replit Proof of Use document
4. `SDC2026_TeamName_Runpod_POU.pdf` - RunPod Proof of Use document

> Replace `TeamName` in the file names with your official registered Team Name.
